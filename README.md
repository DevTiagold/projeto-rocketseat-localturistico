# Local Turístico

**Projeto 01 · Trilha Full Stack · HTML e CSS**

Uma página de apresentação de um local turístico, desenvolvida a partir de uma referência no Figma para colocar em prática os fundamentos de HTML e CSS.

## Sobre o projeto

Este é o primeiro projeto do curso full stack que estou fazendo para aprofundar meus conhecimentos e consolidar minha base em desenvolvimento web.

O exercício está concentrado no front-end: transformar um layout de referência em uma página, trabalhando a estrutura do conteúdo, a disposição dos elementos, os espaçamentos e as imagens.

## Tecnologias e ferramentas

**HTML** para a estrutura da página, **CSS** para a estilização e **Figma** como referência visual para a implementação.

## O que pratiquei

| Fundamento | Aplicação no projeto |
| --- | --- |
| Estrutura HTML | Organização do conteúdo e dos elementos da página. |
| Estilização com CSS | Construção da apresentação visual a partir do layout de referência. |
| Espaçamentos | Uso de `padding` e `margin` para ajustar espaços internos e externos. |
| Containers | Agrupamento do conteúdo e organização das seções. |
| Imagens | Inserção, dimensionamento e integração das imagens à página. |
| Leitura de layout | Observação da referência no Figma e aplicação dos detalhes no código. |

### Principal aprendizado

Mais do que reproduzir uma aparência, este exercício me ajudou a compreender como a estrutura do HTML e as decisões de CSS trabalham juntas na construção de uma página.

O escopo é simples, mas a prática foi importante para transformar conceitos em algo concreto e perceber o impacto dos detalhes no resultado.

## Como visualizar localmente

Baixe ou clone este repositório e abra a pasta do projeto. Em seguida, abra o arquivo HTML principal no navegador, mantendo os arquivos CSS e as imagens nos caminhos utilizados pelo código.
